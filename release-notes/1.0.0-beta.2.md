# gitacre 1.0.0-beta.2

- Added signed automatic updates with controls in Settings.
- Fixed refresh hangs in repositories with large `git` output.
- Unreadable repositories are now shown instead of silently omitted.
- Made repository scanning faster and cached project icons.

Updating from 1.0.0-beta requires one final manual download; later releases can update automatically.

Requires macOS 14 or later. Supports Apple silicon and Intel.
