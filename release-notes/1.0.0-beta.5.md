# gitacre 1.0.0-beta.5

- Refreshes local status on file changes and wake, with a periodic discovery backstop.
- Restores cached repository status at startup and identifies stale results.
- Connects worktrees to pull requests using repository identity, commit, and branch information.
- Shows failing or pending checks, requested reviews, requested changes, merge conflicts, and ready-to-merge status.
- Retains account-scoped PR results during partial refresh failures and applies organization filters before search limits.
- Adds optional PR status-change notifications and a menu-bar indicator for available app updates.
- Expands sanitized diagnostics with scan timings, command failures, cache freshness, and shortcut/update state.

Requires macOS 14 or later. Supports Apple silicon and Intel.
