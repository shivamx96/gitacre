# gitacre 1.0.0-beta

The first public beta of gitacre brings unfinished Git work into a focused native macOS menu-bar app.

## Highlights

- Scan configurable folders for Git repositories and surface pending work.
- Keep linked worktrees grouped beneath their repository.
- See staged, modified, untracked, conflicted, ahead, behind, and stashed states.
- Open a repository directly in Finder, your preferred terminal, or its remote URL.
- View pull requests opened by you and awaiting your review through your existing GitHub CLI session.
- Choose from detected terminal apps including Terminal, iTerm2, Ghostty, Warp, and Alacritty.
- Use a global Option-Command-G shortcut and automatic background refresh.
- Match the system appearance or select light or dark mode.

## Requirements

- macOS 14 Sonoma or later
- Apple silicon or Intel Mac
- GitHub CLI only for the optional Pull Requests view

This is prerelease software. Please report issues through the GitHub repository.
