# gitacre 1.0.0-beta.3

A small maintenance release that completes the automatic-update rollout begun in 1.0.0-beta.2.

## Automatic update verification

This is the first release that 1.0.0-beta.2 can install through gitacre's new updater. There are no user-facing behavior changes in this build; publishing it verifies the signed, notarized Sparkle update path end to end.

Users still running 1.0.0-beta must update manually because that build does not contain the updater.

## Maintenance

- Download links now consistently lead to the newest beta, including when the website cannot reach the GitHub Releases API.
- Release documentation and script guidance now match the actual appcast publication flow.
- The test suite now runs automatically for pushes and pull requests.

## Requirements

macOS 14 or later, Apple silicon or Intel.
