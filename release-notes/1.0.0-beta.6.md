# gitacre 1.0.0-beta.6

- Reduces background Git commands by relying on filesystem events while the watcher is active, filtering irrelevant Git metadata and lock-file activity, and coalescing discovery requests.
- Keeps edits, commits, branch switches, stash changes, and in-progress Git operations up to date, including changes received during startup.
- Avoids redundant repository and GitHub refreshes when reopening the panel shortly after a successful refresh.
- Remembers missing origins and empty repositories between discovery scans, while still detecting a repository's first commit immediately.
- Adds an in-memory performance timeline and session totals, exportable from Settings → Advanced → Export performance… for troubleshooting.
- Improves update feedback and available actions in Settings.

Requires macOS 14 or later. Supports Apple silicon and Intel.
