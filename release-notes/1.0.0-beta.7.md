# gitacre 1.0.0-beta.7

- Prevents repository refreshes from getting stuck when a subprocess exits but leaves an output pipe open.
- Reports temporary GitHub connection and authentication-check failures with a retry action. Keeps cached pull requests available for recovery after the account is verified again.
- Keeps the primary checkout visible when linked worktrees are disabled, including when a linked checkout is discovered first.
- Shows warnings for missing or inaccessible monitored folders instead of presenting an incomplete scan as nothing pending. Warnings survive status refreshes and app restarts until discovery succeeds.
- Loads repository rows lazily and reads and decodes raster icons in the background, with small thumbnails and shared caching.
- Adds stable-release version support and automated website and release-script validation to CI.

Requires macOS 14 or later. Supports Apple silicon and Intel.
